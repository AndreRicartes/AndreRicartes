### Olá! Sou André Ricartes 👋

**Geotecnólogo | Analista de Dados no Agronegócio | Especialista em Regularização Fundiária**

A terra não mente, mas os dados revelam o que os olhos não veem.

Combino **36+ anos de experiência prática de campo** ("boots on the ground") com **Ciência de Dados e Inteligência Artificial**, desenvolvendo soluções para Regularização Fundiária e Agricultura 5.0.

- 🔭 **Atualmente trabalhando em:** Consultoria de Geointeligência (regularização fundiária, laudos periciais via sensoriamento remoto, auditoria de risco territorial).
- 🔬 **Pesquisa:** Sensor de solo com IA para análise de nutrientes (artigo publicado na *Revista Interface Tecnológica*) e MVP de monitoramento automatizado de agricultura vertical hidropônica com IoT (artigo aprovado, publicação em breve). Projetos com apoio do **Inova CPS**.
- 📍 **Foco:** Transformar dados complexos (satélite/cartografia) em segurança jurídica e eficiência agronômica.
